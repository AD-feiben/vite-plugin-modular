# 优化 CLI 日志打印和耗时统计

## 现状分析
- 当前使用简单的 `console.log` 和 `console.error` 打印信息
- 已使用一些 emoji 图标增强视觉效果，但格式不统一
- 缺乏执行耗时统计
- 日志层次不够清晰，可读性待提升
- 项目尚未安装 chalk 库

## 优化方案

### 1. 添加 chalk 依赖
- 在 package.json 中添加 chalk 依赖
- 确保安装最新版本的 chalk

### 2. 创建日志工具类
- 创建 `src/utils/logger.ts` 文件
- 使用 chalk 实现不同级别的日志方法：info、success、warning、error
- 添加时间戳、emoji 图标和颜色
- 支持自定义日志前缀和样式

### 3. 添加耗时统计功能
- 在日志工具类中添加耗时统计方法
- 为每个命令执行添加开始和结束时间记录
- 在命令完成时显示执行耗时
- 支持毫秒和秒两种时间格式

### 4. 统一日志格式
- 为所有命令使用统一的日志风格
- 标准化成功、警告、错误等不同类型的日志格式
- 添加命令执行的开始和结束标记
- 使用一致的 emoji 图标和颜色方案

### 5. 修改 CLI 命令文件
- 更新所有命令文件（add.ts、delete.ts、list.ts 等）
- 替换直接的 `console.log` 调用为新的日志工具方法
- 在每个命令执行前后添加耗时统计
- 优化命令执行结果的展示格式

### 6. 增强用户体验
- 添加命令执行的进度提示
- 为重要操作添加确认信息
- 优化错误信息的展示，提供更清晰的错误原因
- 添加命令执行成功的总结信息

## 预期效果
- 使用 chalk 提供的颜色和样式使日志更加美观
- 日志信息更加统一和易读
- 用户可以清晰了解命令执行的耗时
- 不同类型的信息通过颜色和图标区分，提高可读性
- 命令执行过程更加透明，用户体验更好
