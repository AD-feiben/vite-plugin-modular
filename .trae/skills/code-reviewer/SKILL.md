# 代码审查与优化工具

此技能用于自动审查代码，识别重复代码，并提供优化建议，帮助提高代码质量和可维护性。

## 工作原理

1. **代码分析**：扫描代码库，识别重复代码片段
2. **模式检测**：检测常见的代码异味和优化机会
3. **建议生成**：根据分析结果生成优化建议
4. **报告生成**：生成详细的审查报告

## 审查范围

- **重复代码**：识别重复或高度相似的代码片段
- **代码结构**：检查代码结构和组织
- **命名规范**：验证变量、函数和类的命名
- **性能问题**：检测潜在的性能瓶颈
- **最佳实践**：检查是否遵循最佳实践

## 何时调用

调用此技能当：
- 完成代码修改后
- 准备提交代码前
- 项目代码质量下降时
- 用户明确要求代码审查或优化
- 想要识别和消除重复代码时

## 使用示例

### 示例1：代码修改后审查

**场景**：完成了一个新功能的开发，想要确保代码质量

**调用方式**：
```
代码审查
```

**输出**：
- 重复代码检测结果
- 优化建议
- 代码质量评分

### 示例2：优化特定文件

**场景**：想要优化某个特定文件中的重复代码

**调用方式**：
```
审查并优化 src/utils/index.ts
```

**输出**：
- 该文件的审查结果
- 针对该文件的优化建议
- 优化前后的对比

## 优化建议类型

1. **提取重复代码**：将重复代码提取为函数或组件
2. **重构代码结构**：优化代码的组织结构
3. **改进命名**：提供更清晰的命名建议
4. **性能优化**：优化潜在的性能问题
5. **最佳实践建议**：建议遵循行业最佳实践

## 技术实现

- 使用 AST (抽象语法树) 分析代码
- 采用基于哈希的重复代码检测算法
- 结合规则引擎进行代码审查
- 生成结构化的审查报告

## 最佳实践

- 定期运行代码审查，保持代码质量
- 优先处理重复代码，提高代码复用性
- 参考优化建议，但根据实际情况进行调整
- 将代码审查集成到开发工作流程中

## 注意事项

- 审查结果仅供参考，最终决策由开发人员决定
- 对于复杂的代码库，审查可能需要较长时间
- 某些优化建议可能需要结合业务上下文进行评估
- 建议与其他代码质量工具结合使用
